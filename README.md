# EasyWei · ”卫戍协议：规程“图鉴https://yulvy.github.io/EasyWei/
一个双端可用的由github代理的网页https://yulvy.github.io/EasyWei/，复制就能在浏览器打开，功能不全，也没有识别功能，只是为了拯救我这种金鱼记忆无法记住所有盟约的人orz

> 单文件、离线可用的《明日方舟》卫戍协议资料站：干员盟约、交叉关系、叠层上限、敌人轮选 / 赛季图鉴与装备库。

这是一个粉丝向资料整理项目，不是官方 Wiki。整个站点只有一个 HTML 文件，图片、数据、样式和脚本全部内嵌，不需要后端、数据库或构建工具。


## 功能

- **干员图鉴**：143 名干员，可按核心盟约、小盟约、等阶、触发时机和收录类型筛选。
- **关系表**：10 个核心盟约 × 8 个交叉小盟约，包含 9 名双小盟约桥梁干员、覆盖率和桥梁索引。
- **叠层上限**：大盟约 / 小盟约 × I–VI 阶，共 149 条单回合叠层记录。
- **原图存档**：13 张关系图与叠层表集中存放，点击可查看大图。
- **敌人图鉴**：
  - 机变策略敌人轮选：115 条记录，按出现轮次和赏金分区。
  - 当前赛季敌人图鉴：9 个分类、179 名唯一敌人，每项可跳转 PRTS。
- **装备库**：70 件装备，按 T1–T6 分组，列出基础 / 进阶效果、售价和描述。
- **响应式**：桌面端与手机端均可使用。

## 数据维护

所有数据都在 `stronghold-wiki.html` 内的 `const DB = { ... }` 中：

| 字段 | 内容 |
|---|---|
| `DB.operators` | 干员基础数据、效果、盟约、等阶 |
| `DB.hiddenOperators` | 隐藏干员，初始化时并入 `DB.operators` |
| `DB.covenants` | 核心 / 小盟约说明 |
| `DB.enemyRotation` | 机变策略敌人轮选 |
| `DB.enemyCompendium` | 当前赛季战术特训敌人 |
| `DB.equipment` | 装备数据 |
| `DB.relationship` | 交叉关系、叠层上限、13 张原图 |
| `DB.avatars` | 干员头像 data URI |

修改后保存文件并刷新浏览器即可，不需要重新构建。注意保持 JavaScript 对象语法正确。

## 已知限制

- 页面约 3.5 MB，主要来自内嵌头像和 13 张原图；首次打开需要下载完整文件。
- PRTS 与 B站链接需要联网；主体页面本身可离线使用。
- PRTS 数据会随游戏版本变化，敌人和装备内容需要手动更新。
- 页面没有后端，筛选和搜索都在浏览器本地完成。
